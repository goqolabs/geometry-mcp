## When to open a GitHub Issue

**Use Issues for transport / product failures**, for example:

- Gateway errors (HTTP 5xx, timeouts, empty or truncated responses)
- Client cannot complete the MCP handshake after following [Quickstart](/quickstart)
- A tool throws or returns malformed JSON (missing required keys, not “I expected a different sign”)

**Do not open Issues for** zodiac / calendar disagreements — read [Astro wheels](/astro-wheels) and [Calendar boundaries](/calendar-boundaries) first. The catalog and wheels are pre-validated; different systems are supposed to diverge.

**Open an issue:** [github.com/goqolabs/geometry-mcp/issues](https://github.com/goqolabs/geometry-mcp/issues/new) — title it clearly (e.g. `Bug: mcp.geometry.app returns 502 on get_card_for_birthdate`).

## Make a bug report worth filing

Incomplete reports get closed or delayed. Include:

| Include | Example |
|---|---|
| What failed | `502` / timeout / empty body / MCP connect error |
| Tool name and exact inputs | `get_card_for_birthdate`, `birth_date: 1985-03-15` |
| Client + URL shape | e.g. Cursor · soft-launch URL (no key) |
| Time (UTC) and any request id if you have one | when the 5xx happened |
| For malformed JSON only: the `_no` values from the broken block | `system_no: 16021`, `planet_no: 8` |

Those `_no` fields are internal catalog ids — not a public API contract (see [Field glossary](/field-glossary)) — but quoting them helps reproduce a broken payload shape.

## Leaked key

1. **Roll** the key in the Developer Portal immediately — [Connect & manage your key → Rotation](/connect-and-keys#rotation).  
2. Update your connector URL to the new key.  
3. The old key stays valid for **7 days** (Zuplo grace). That is normal vendor behavior.

Almost every leak is fully handled by steps 1–2. Early kill before the grace window is rare and operator-only — see [Connect & manage your key](/connect-and-keys#if-your-key-was-exposed).

## Tips

- One Issue per bug.  
- Link the docs page you were on if it helps.  
- A free GitHub account is required to open Issues.  
- There is **no** public product support email.
