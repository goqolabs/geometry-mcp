Mintlify’s in-docs **Ask Assistant** can answer from this site when it is enabled on the docs plan. Prefer it for “where is X?” and install wording before opening an Issue.

## When to open a GitHub Issue

**Only for suspected product bugs** — wrong tool output, crash, or gateway error that the docs do not explain.

**Open an issue:** [github.com/goqolabs/geometry-mcp/issues](https://github.com/goqolabs/geometry-mcp/issues/new) — title it clearly (e.g. `Bug: get_card_for_birthdate wrong sign for 1985-03-15`).

### Do not open Issues for

| Topic | Why |
|-------|-----|
| How to connect / paste the URL | Covered by [Quickstart](/quickstart) and [geometry.app/tutorial](https://geometry.app/tutorial/) |
| “Where is the docs for…?” | Use nav, search, or [FAQ](/faq) |
| Key rotation / normal revoke | [Connect & manage your key](/connect-and-keys) — Roll API Key |
| Billing / plans | Stripe + Developer Portal |
| Feature ideas / roadmap | Not a support channel right now |

## Make a bug report worth filing

Incomplete reports get closed or delayed. Include:

| Include | Example |
|---|---|
| Tool name and exact inputs | `get_card_for_birthdate`, `birth_date: 1985-03-15` |
| What you got vs what you expected | “expected Western tropical sign for March; got `sign_name: \"none\"`” |
| The `_no` values from the wrong block | `system_no: 16021`, `planet_no: 8`, `element_no: 1700` |
| Client + URL shape | e.g. Cursor · soft-launch URL (no key) |

Those `_no` fields are internal catalog ids — not a public API contract (see [Field glossary](/field-glossary)) — but quoting them lets a solo maintainer reproduce your case without guessing.

## Leaked key

1. **Roll** the key in the Developer Portal immediately — [Connect & manage your key → Rotation](/connect-and-keys#rotation).  
2. Update your connector URL to the new key.  
3. The old key stays valid for **7 days** (Zuplo grace). That is normal vendor behavior.

Almost every leak is fully handled by steps 1–2. Early kill before the grace window is rare and operator-only — see [Connect & manage your key](/connect-and-keys#if-your-key-was-exposed).

## Tips

- One Issue per bug.  
- Link the docs page you were on if it helps.  
- A free GitHub account is required to open Issues.  
- There is **no** public product support email.
