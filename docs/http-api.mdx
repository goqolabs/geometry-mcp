GEOMETRY’s **supported** surface for AI apps is **[MCP](/quickstart)** (`https://mcp.geometry.app/mcp`). Soft launch is **MCP-only**.

**HTTP / REST** remains a **parked secondary door** for apps, scripts, and pipelines that are not MCP-native. Same three tools and JSON contracts — different transport — when that door opens later.

## Status

| Surface | Role | Today |
|---------|------|--------|
| **MCP** | Connectors in Claude, ChatGPT, Cursor, VS Code, and other MCP clients | **Live and supported** — [Quickstart](/quickstart) |
| **HTTP API** | JSON over HTTP for apps and scripts | **Deferred** — branded **`api.geometry.app`** is reserved DNS only (no public routes yet). Not part of soft launch |

This page is kept so builders know the plan. It does **not** mean REST is available or cancelled — only that it is **not shipping now**.

When a real non-MCP builder need appears, this page will add curl examples, auth (`?key=`), and rate-limit notes — still pointing at the same tools:

- [`get_date`](/tools/get-date)
- [`get_compatibility`](/tools/get-compatibility)
- [`get_name`](/tools/get-name)

## What stays the same

- Inputs (e.g. bare `YYYY-MM-DD`) and complete JSON outputs
- Coverage window and calendar rules — [When it covers](/coverage)
- Keys and rotation — [Where your key goes](/connect-and-keys)  
- Checkout / invoices — [Billing](/billing)
- Payload field meaning — [What you get](/payload-shapes) · [Field glossary](/field-glossary)

## What to use now

1. Use **MCP** — that is the live product door ([Quickstart](/quickstart)).
2. Do **not** call or announce `https://api.geometry.app/…` yet — there is no public branded HTTP route to document.
3. Questions about zodiac or calendar disagreement belong in [Astro wheels](/astro-wheels) / [FAQ](/faq) — not “API vs MCP.”
