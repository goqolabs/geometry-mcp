A name string in → per-word and full-name **Francis Bacon** cosmic cards, Pythagorean Expression / Soul Urge / Personality, Latin cipher suite sums, Chaldean `periodic{}`, and multi-cipher `periodic_set{}` (chaldean / ordinal / reduction). Each word also carries the same card siblings as [`get_date`](/tools/get-date) (tarot, medicine, iching, chakra, lenormand, karma, planetary spread).

<Info>
  **When to use:** a person or word **name** only. Not for dates, moon phase, season, retrogrades, or Life Path — those are [`get_date`](/tools/get-date).
</Info>

## Warning — rare Unicode glyphs in chat copies

`periodic.alchemical_symbol` uses characters from the Unicode **Alchemical Symbols** block (U+1F700–U+1F77F) and classical planetary glyphs. Those are **correct in the live MCP / HTTP response**.

When an LLM **retypes or “saves” JSON into a chat file**, it often **substitutes lookalike emoji** for those rare glyphs. Numbers, names, cards, and cipher sums usually stay intact — only the glyph field flips.

| Live tool response | Corrupted chat copy (example) |
|---|---|
| Phosphorus `🝁` **U+1F741** | `🩁` U+1FA41 |
| Oxygen `🜊` **U+1F70A** | `🌊` U+1F30A |

**This is not a GEOMETRY data bug.** Use the live tool response. Prefer asking the model to paste the **tool result unchanged**, or verify with codepoints (`U+1F70A`). Same hazard on Claude, ChatGPT, and other LLMs. Details: [FAQ](/faq#llm-unicode-glyphs).

## What you get

- Top-level `cipher_legend[]` once — **~100 active Latin ciphers** (`script_type = latin` and `is_active`; count can move slightly as the catalog grows)
- `words[]` — one entry per whitespace-separated word plus a `"full"` aggregate. Array length varies with the name (1 word → 2 entries; 3 words → 4); use your language’s array length (e.g. JavaScript `words.length`).
- Each word / full: Francis Bacon `card{}` (also called destiny card), `name_role` (`only` / `first` / `middle_N` / `last` / `full`), `arcs{}`, `archetype{}`, `numerology{}` (Expression / Soul Urge / Personality), legacy `periodic{}` (Chaldean), `periodic_set{}` (chaldean / ordinal / reduction), `ciphers[]` of `{ cipher_no, raw_sum }`, plus card siblings `karma` / `planetary_spread` / `medicine` / `tarot` / `iching` / `chakra` / `lenormand` — join cipher sums to the legend by `cipher_no`
- Top-level `numerology{}` is a copy of the **full** row’s numerology (the whole-name Expression / Soul Urge / Personality)
- **41** (`francis_bacon`) drives the cosmic `card{}`; **42** (`pythagorean`) drives Expression (all letters), Soul Urge (vowels A E I O U; Y is always a consonant), and Personality (consonants); **27** (`chaldean`) drives `periodic{}` / alchemical wrap
- Path numbers keep **11 / 22 / 33** when the raw sum is exactly those values; every other total reduces to a single digit. `*_base` is the single-digit collapse of a kept 11/22/33. Some books stop at a first-pass 11; this engine’s number is the fully reduced path (same rule as Life Path on [`get_date`](/tools/get-date)). Builders who want that first-pass reading compute it from `{stem}_sum`.
- Expression is also called Destiny. Soul Urge is also called hearts desire. On master paths **11 / 22 / 33**, `also_called` also carries the vernacular title (`master_illuminator` / `master_builder` / `master_transmutator`). These aliases exist on `get_name` only — not on date tools.
- **Chakra** and **I Ching** on each word use the same **card** helpers as [`get_date`](/tools/get-date) (element / unirank / atomic bridge) — not a Chaldean “mod 7” or “mod 64” from the name sum.

Live payloads always include the **full** legend + matching `ciphers[]` arrays. Docs samples (KEEL · Ohtani · ROBERT) are abbreviated on purpose — do **not** paste a static 100-row table here; use `cipher_legend` from the tool.

### Numerology fields (per stem)

Stems: `expression` · `soul_urge` · `personality`.

| Field | Meaning |
|-------|---------|
| `{stem}_sum` | Raw Pythagorean total (cipher **42**; Expression reuses the row’s `ciphers[]` entry) |
| `{stem}` | Path number — keeps **11 / 22 / 33** when raw is exactly those; else single digit |
| `{stem}_base` | Single-digit collapse of a kept master (11→2, 22→4, 33→6); else same as `{stem}` |
| `is_master_{stem}` | `true` only when raw ∈ {11, 22, 33} |
| `{stem}_name` | Canonical path name (`visionary` / `architect` / `healer` on masters) |
| `core_theme` / `keyword` / `strength` / `shadow` | Meaning tokens for that path |
| `also_called` | Present when there is at least one alias — see above |
