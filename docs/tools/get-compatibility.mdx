Two dates in → **Cosmic card A** and **Cosmic card B**, connections between them, and a scored breakdown. Scoring follows the cardology connection system (Cards of Destiny / Robert Camp tradition).

<Info>
  **When to use:** comparing **two** dates only (`date_a`, `date_b`). For a single date → [`get_date`](/tools/get-date).
</Info>

<Info>
  **One call returns** two full date profiles (each the same shape as [`get_date`](/tools/get-date) — Cosmic card + calendars, moon, season, Rx, and the rest) plus a weighted compatibility score and cross-wheel aspects. Each side’s `cosmic.planetary_spread` includes **`spread_pos`** (1–14) — sort by that field; see [get_date → Planetary spread order](/tools/get-date#planetary-spread).
</Info>

| | |
|---|---|
| **Input** | `date_a`, `date_b` (YYYY-MM-DD) |
| **Range** | Same coverage bands as [`get_date`](/tools/get-date) — `temporal_context.date_a` / `date_b` = `full` inside 1900–2100; `extended` nearby; farther out → `out_of_range` with Cosmic-card-only scope |
| **Version** | `v1.8.10` |
| **MCP URL** | `https://mcp.geometry.app/mcp` |

**Ask:**

> How compatible are 1985-03-15 and 1990-11-08?

Live payloads are large (~85 KB). Below is a teaching excerpt — Cosmic card A / B profiles abbreviated.

**Full payload / raw JSON:** call this tool — live response is the complete object (no verbosity flag). Chat may summarize; ask for the raw tool result if the UI truncates.

## How scoring works (do one pair by hand)

You can score **one** pair yourself. Use the MCP tool when you have **many** dates or many permutations — same math, just faster.

Most real pairs have **different** Cosmic cards. Same-card matches are rare; the first example below shows one on purpose so you can see the same-card line, then a second example shows the usual case.

### Chinese bonus table (what enters the score)

| Scored Chinese aspect | Bonus |
|----------------------|------:|
| `trine` (San He) | **+13** |
| `harmonic_pair` (Liu He) | **+8** |
| `sextile` | +3 |
| `semisextile` | +2 |
| `quincunx` | −2 |
| `square` | −5 |
| `opposition` | −8 |
| `none` | 0 |

Only `chinese_zodiac_bonus` is summed. If you also see `chinese_wheel_aspect` / `chinese_wheel_bonus`, that is a leftover Western-grid label — **do not add it**.

<a id="example-liu-he"></a>

### Example A — Liu He + same Cosmic card (uncommon)

**Dates:** `2029-02-27` × `2024-02-27` (rooster × dragon — Chinese **secret-friend** / Liu He).

| Date | Animal | Cosmic card |
|------|--------|-------------|
| 2029-02-27 | **rooster** | same card as B |
| 2024-02-27 | **dragon** | same card as A |

Scored Chinese aspect = **`harmonic_pair`** → **`chinese_zodiac_bonus` = +8**.

| Line | Value | Notes |
|------|------:|-------|
| Same Cosmic card | **+13** | Both dates share one Cosmic card |
| Element harmony | **+5** | Harmonious classical elements |
| Ruling-planet bonus | **0** | Neutral |
| Card connections (`card_score.combined`) | **0** | No scored cardology edges here |
| Chinese zodiac (Liu He) | **+8** | From the table |
| True sidereal / other wheels | *(shown, not added)* | Policy `v1` |

```text
13 + 5 + 0 + 0 + 8 = 26
```

Live check: `overall_score` **26**, `chinese_zodiac_aspect` **`harmonic_pair`**, `interpretation` **`deeply_harmonious`**.

<a id="example-san-he"></a>

### Example B — San He trine + different Cosmic cards (typical)

**Dates:** `2024-03-01` × `2028-06-15` (dragon × monkey — Chinese **San He** / trine). Cosmic cards differ.

| Date | Animal | Cosmic card |
|------|--------|-------------|
| 2024-03-01 | **dragon** | **9♠** |
| 2028-06-15 | **monkey** | **2♦** |

Scored Chinese aspect = **`trine`** → **`chinese_zodiac_bonus` = +13**. Wheel leftover is `none` / 0 (San He has no 9027 Western-grid twin).

| Line | Value | Notes |
|------|------:|-------|
| Same Cosmic card | **0** | 9♠ ≠ 2♦ — usual case |
| Element harmony | **−3** | Challenging classical elements |
| Ruling-planet bonus | **+1** | Slight planetary edge |
| Card connections (`card_score.combined`) | **+1** | One scored cardology edge |
| Chinese zodiac (San He) | **+13** | From the table |
| True sidereal / other wheels | *(shown, not added)* | Policy `v1` |

```text
0 + (-3) + 1 + 1 + 13 = 12
```

Live check: `overall_score` **12**, `chinese_zodiac_aspect` **`trine`**, same-card bonus **0**.

### When to use the tool

| Situation | Do this |
|-----------|---------|
| One or two dates | Score by hand with the table above (or one MCP call to confirm) |
| Many birthdays, a roster, or all permutations | Call `get_compatibility` repeatedly — same formula, no hand arithmetic |

The six Liu He pairs: rat–ox · tiger–pig · rabbit–dog · **dragon–rooster** · snake–monkey · horse–goat.  
San He (trine) groups: rat–dragon–monkey · ox–snake–rooster · tiger–horse–dog · rabbit–goat–pig.

  **Wire names:** inputs and `temporal_context` use **`date_a` / `date_b`**. Full date profiles are **`cosmic_card_a` / `cosmic_card_b`**. Out-of-range Cosmic-card-only scope uses `payload_scope: "cosmic_card_only"`. Cosmic card = birth = life = sun (`cosmic.also_called`).
</Note>
