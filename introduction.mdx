GEOMETRY answers **date-keyed** questions with **fixed, structured JSON**. Connect it once over MCP; Claude Code, Claude Desktop, ChatGPT, Codex, Cursor, VS Code, and other clients can call it mid-conversation.

<Tip>
  **Prefer Claude** for natural-language asks — enable once and stay in the thread. ChatGPT uses the same URL; use `@geometry Call get_…`, and start a **new chat if the tool drops** — [quirks](/quickstart#chatgpt-known-quirks).
</Tip>

- Cosmic cards, calendars, moon phases, seasons, retrogrades, and related systems on a **1900–2100** date range
