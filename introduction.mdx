# GEOMETRY

GEOMETRY is a **deterministic temporal semantic layer** for LLMs. You ask date-keyed questions; you get the same structured JSON every time.

**Public MCP URL (canonical):**

```
https://mcp.geometry.app/mcp
```

Site: [geometry.app](https://geometry.app) · Company: [goqo.com](https://goqo.com)

## What you get

- Birth cards, calendars, moon phases, seasons, retrogrades, and related systems on a **1900–2100** date spine
- MCP tools for Claude, Cursor, and other clients — no Node install for the hosted path
- Public beta: data layer is stable; quotas and tooling still evolve
