GEOMETRY answers **date-keyed** questions with **fixed, structured JSON**. Connect it once over MCP; Claude Code, Claude Desktop, ChatGPT, Codex, Cursor, VS Code, and other clients can call it mid-conversation.

Ask for a birth card, a cultural year, a moon phase, a season, or active retrogrades — you get the same result every time for the same date.

## What you get

- Birth cards, calendars, moon phases, seasons, retrogrades, and related systems on a **1900–2100** date range
- Hosted MCP tools — no local Node install for the connector URL
- Soft launch: the data layer is stable; self-serve keys and quotas are still rolling out. The free URL works to try

These docs show shortened teaching samples. Every live tool call returns the **complete** JSON. See [Tools](/tools/overview).
