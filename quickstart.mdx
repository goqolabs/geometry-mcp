# Quickstart

Copy. Paste. Ask.

## Claude Code / CLI

```bash
claude mcp add \
  --scope user \
  --transport http \
  geometry https://mcp.geometry.app/mcp
```

Works on the free / anonymous trial immediately — no signup to try.

## Claude Desktop

1. **Settings → Connectors → Add custom connector**
2. URL: `https://mcp.geometry.app/mcp`
3. Save — then ask in a conversation

## Then ask your AI

- "What's the birth card for March 15, 1985?" — *birth identity*
- "How compatible are two people born 1985-03-15 and 1990-11-08?" — *two people*
- "What's the card and planetary ruler for today, 2026-07-28?" — *one day*
- "What moon phase and season was 1985-03-15, and was anything retrograde?" — *deeper birth context*

The first, second, and third questions map to the three tools: birth identity, a pair, and a single day. The fourth is the same birth-identity tool — moon phase, season, and retrogrades all travel inside the birth payload, so no extra call is needed.

**Want the full payload in chat?** (same as “raw JSON”)

> give raw json for birthdate 1985-03-15 card

That is an instruction to the **agent** to paste the complete tool result. The tool itself has no verbosity flag — only `birth_date`. Developers / RAG builders reading MCP or HTTP responses already get the full object on every call.

**Promise:** No accounts to try it. No hallucinated dates. Same answer every time.

## Free vs paid URL

| | URL |
|---|---|
| Free / anonymous trial | `https://mcp.geometry.app/mcp` |
| Paid (or Free plan with a key) | `https://mcp.geometry.app/mcp?key=YOUR_KEY` |

Upgrading changes **nothing else** in the client config — swap the URL string. See [Connect & manage your key](/connect-and-keys).
