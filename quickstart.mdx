Copy the connector URL, paste it into your MCP client, then ask a date question.

<Note>
  **Public beta.** The **data layer is stable** — same date, same JSON, every time. Tooling and quotas are still evolving. No account needed to try the free URL below; limits and plans live on [pricing](https://geometry.app/pricing/).
</Note>

<Tip>
  **Prefer Claude** (Claude Code or Claude Desktop) for natural-language date questions. After you enable the Geometry connector once, Claude usually picks the right tool mid-thread without `@` syntax. ChatGPT works on the **same MCP URL** but needs more explicit prompting to pick the right tool — see [ChatGPT quirks](#chatgpt-known-quirks) below.
</Tip>

## With or without a key

| | URL |
|---|---|
| No key — try it now | `https://mcp.geometry.app/mcp` |
| With your key | `https://mcp.geometry.app/mcp?key=YOUR_KEY` |

The keyless URL is open during soft launch — no account. A key comes from any Developer Portal subscription (metered Free **or** paid), so a key is not the same as "paid"; append it as `?key=` — same shape for every client below. Details: [Where your key goes](/connect-and-keys).

## Claude Code / CLI

```bash
claude mcp add \
  --scope user \
  --transport http \
  geometry https://mcp.geometry.app/mcp
```

Works immediately on the free trial URL — no signup. `--scope user` writes to `~/.claude.json` (all projects). Confirm with `/mcp` inside Claude Code.

Visual: [tutorial · Claude Code](https://geometry.app/tutorial/#claude-code).

## Claude Desktop

1. Open **Connectors** from the compose **+** menu (or **Settings → Connectors**)
2. **+ Add connector** → **Add custom connector**
3. Name: `geometry` · URL: `https://mcp.geometry.app/mcp`
4. Leave **Advanced settings** empty (no OAuth for soft launch)
5. **Add** — then **toggle geometry ON** (easy to miss)
6. Ask a date question in a conversation

Visual: [tutorial · Claude Desktop](https://geometry.app/tutorial/#claude).

## ChatGPT (Plugins)

Same remote MCP URL — ChatGPT calls these **Plugins** (Claude calls them **Connectors**). Soft launch: **Authentication = No Auth**.

<Warning>
  **Recommend Claude** for natural-language date questions. ChatGPT uses the same MCP URL and can work well — but Plugins MCP is **inconsistent**: sometimes a follow-up in the same thread succeeds, sometimes the next turn drops the tool and you need a **new chat**. Always use **`@geometry Call get_…`**. The data is stable; the **host** is flaky. Prefer [Claude Desktop](#claude-desktop) or [Claude Code](#claude-code--cli) when teaching “just ask.”
</Warning>

### Install once

1. **Settings → Security and login → Developer mode** on (plan / workspace dependent)
2. Open [chatgpt.com/plugins](https://chatgpt.com/plugins) → **+** → **New Plugin**
3. Name `geometry`, paste `https://mcp.geometry.app/mcp`, set **No Auth**, accept the risk checkbox → **Create**
4. **Connect** on the consent screen — then `geometry` shows under Installed

### Use it in a chat (handhold more than Claude)

**Required pattern:** type **`@geometry`**, then **name the tool** and args. Do not rely on bare natural language or the Plugins **+** chip alone.

```text
@geometry Call get_birthdate for 1990-06-15. Confirm tool_version and temporal_context.
```

```text
@geometry Call get_compatibility for 1990-06-15 and 1985-11-02. Confirm tool_version and overall score.
```

```text
@geometry Call get_day for 2026-07-28. Confirm tool, tool_version, day card, day ruler.
```

```text
@geometry Call get_name for KEEL. Confirm tool and tool_version.
```

<a id="chatgpt-known-quirks"></a>

### ChatGPT known quirks (dogfood 2026-07)

| Quirk | What you’ll see | What to do |
|-------|-----------------|------------|
| **Must `@geometry` + tool name** | Without it, ChatGPT web-searches or invents (e.g. wrong Destiny Card) | Always `@geometry Call get_…` |
| **Inconsistent same-thread** | After a success, the **next** ask sometimes works in-thread, sometimes “tool isn’t available” | Try once with `@geometry`; if it drops → **new chat**. Do not trust same-thread as reliable |
| **Wrong tool** | Calls `get_day` for moon / Rx / leap year | Name **`get_birthdate`**; for calendar facts say “do not call get_day” |
| **Web search mix-in** | Cites mooninfo.org while claiming Geometry | “Answer ONLY from the tool JSON. Do not use web search.” |
| **+ chip vanishes** | Composer Plugins chip disappears mid-thread | Ignore the chip; use `@geometry` |

| Approach | When |
|----------|------|
| **`@geometry` + tool name** | **Default** every ChatGPT ask |
| **New chat** | Whenever invoke fails or feels stuck — **normal ops**, not a GEOMETRY outage. Same-thread success is a bonus, not a promise |
| Composer **+** → geometry chip | Optional; often vanishes — don’t rely on it |

**Without** `@geometry` (or the chip), ChatGPT may invent answers from the web. Look for **Called tool** above a real answer.

**Tool routing:** moon / season / Rx / calendars / weekday / leap year → **`get_birthdate`**. Day card / weekday ruler only → **`get_day`**. Two people → **`get_compatibility`**. Name → **`get_name`**.

**Claude vs ChatGPT:** same MCP URL. **Claude (recommended)** — enable once, natural language, stay in the thread. **ChatGPT** — `@geometry Call get_…`; treat new-chat-as-needed as expected. Prefer Claude for demos and “just ask.”

## Cursor

1. **Cursor Settings → Tools & MCP → New MCP Server** (opens `mcp.json`)
2. Add the remote server:

```json
{
  "mcpServers": {
    "geometry": {
      "url": "https://mcp.geometry.app/mcp"
    }
  }
}
```

3. **Toggle geometry ON** in Tools & MCP (easy to miss)
4. Ask a date question in Agent

Project file: `.cursor/mcp.json` · global: `~/.cursor/mcp.json`.

Visual: [tutorial · Cursor](https://geometry.app/tutorial/#cursor).

## VS Code

1. **Command Palette** → `MCP: Add Server` (or `MCP: Open Workspace Folder MCP Configuration`)
2. Add to `.vscode/mcp.json`:

```json
{
  "servers": {
    "geometry": {
      "type": "http",
      "url": "https://mcp.geometry.app/mcp"
    }
  }
}
```

3. **MCP: List Servers** — confirm geometry is Running
4. Ask a date question in Copilot Chat **Agent** mode

User profile: `MCP: Open User Configuration`. Key is `servers` (not Cursor’s `mcpServers`); HTTP needs `"type": "http"`.

Visual: [tutorial · VS Code](https://geometry.app/tutorial/#vscode).

## Then ask your AI

| Question type | Tool | Example |
|---------------|------|---------|
| Moon / season / Rx / calendars / birth card / weekday / leap year | [`get_birthdate`](/tools/get-birthdate) | "What day of the week was 2000-02-29, and was that a Gregorian leap year?" |
| Birth identity | [`get_birthdate`](/tools/get-birthdate) | "What's the birth card for March 15, 1985?" |
| Two people | [`get_compatibility`](/tools/get-compatibility) | "How compatible are 1985-03-15 and 1990-11-08?" |
| Day card + weekday ruler only | [`get_day`](/tools/get-day) | "What's the day card and planetary ruler for 2026-07-28?" |
| Name → cards | [`get_name`](/tools/get-name) | "Decode the name KEEL" |

Moon phase, season, and retrogrades ship **inside** [`get_birthdate`](/tools/get-birthdate) — not [`get_day`](/tools/get-day).

**ChatGPT one-liners** (copy-paste):

```text
@geometry Call get_birthdate for 1986-01-05.
```

```text
@geometry Call get_day for 2026-07-28.
```

**Full JSON in chat** (same as “raw JSON”):

> give raw json for birthdate 1985-03-15 card

That tells the **agent** to paste the complete tool result. The tool has no verbosity flag — only `birth_date`. If you read the MCP or HTTP response in code, you already get the full object every call.

No account to try. Fixed lookups — same date, same answer.
