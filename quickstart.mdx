# Quickstart

Copy the connector URL, paste it into your MCP client, then ask a date question.

<Tip>
  Prefer a visual? [Claude Desktop install walkthrough](https://geometry.app/tutorial/) on geometry.app.
</Tip>

## Claude Code / CLI

```bash
claude mcp add \
  --scope user \
  --transport http \
  geometry https://mcp.geometry.app/mcp
```

Works immediately on the free trial URL — no signup.

## Claude Desktop

1. **Settings → Connectors → Add custom connector**
2. URL: `https://mcp.geometry.app/mcp`
3. Save — then ask in a conversation

## Then ask your AI

- "What's the birth card for March 15, 1985?" — *birth identity*
- "How compatible are two people born 1985-03-15 and 1990-11-08?" — *two people*
- "What's the card and planetary ruler for today, 2026-07-28?" — *one day*
- "What moon phase and season was 1985-03-15, and was anything retrograde?" — *deeper birth context*

Those map to the three tools: [`get_card_for_birthdate`](/tools/get-card-for-birthdate), [`get_compatibility`](/tools/get-compatibility), and [`get_day_card`](/tools/get-day-card). Moon phase, season, and retrogrades ship inside the birth-card payload — no extra call.

**Full JSON in chat** (same as “raw JSON”):

> give raw json for birthdate 1985-03-15 card

That tells the **agent** to paste the complete tool result. The tool has no verbosity flag — only `birth_date`. If you read the MCP or HTTP response in code, you already get the full object every call.

No account to try. Fixed lookups — same date, same answer.

## Free vs paid URL

| | URL |
|---|---|
| Free / anonymous trial | `https://mcp.geometry.app/mcp` |
| Paid (or Free plan with a key) | `https://mcp.geometry.app/mcp?key=YOUR_KEY` |

Upgrading changes **nothing else** in the client config — swap the URL string. See [Connect & manage your key](/connect-and-keys).
