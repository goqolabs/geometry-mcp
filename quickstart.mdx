Copy the connector URL, paste it into your MCP client, then ask a date question.

## Try now vs portal key

| | URL |
|---|---|
| Soft launch — no key | `https://mcp.geometry.app/mcp` |
| Portal subscription — add your key | `https://mcp.geometry.app/mcp?key=YOUR_KEY` |

Soft launch needs no account. Once you subscribe in the Developer Portal (metered Free **or** paid), append `?key=` — same shape for every client below. Details: [Where your key goes](/connect-and-keys).

## Claude Code / CLI

```bash
claude mcp add \
  --scope user \
  --transport http \
  geometry https://mcp.geometry.app/mcp
```

Works immediately on the free trial URL — no signup. `--scope user` writes to `~/.claude.json` (all projects). Confirm with `/mcp` inside Claude Code.

Visual: [tutorial · Claude Code](https://geometry.app/tutorial/#claude-code).

## Claude Desktop

1. Open **Connectors** from the compose **+** menu (or **Settings → Connectors**)
2. **+ Add connector** → **Add custom connector**
3. Name: `geometry` · URL: `https://mcp.geometry.app/mcp`
4. Leave **Advanced settings** empty (no OAuth for soft launch)
5. **Add** — then **toggle geometry ON** (easy to miss)
6. Ask a date question in a conversation

Visual: [tutorial · Claude Desktop](https://geometry.app/tutorial/#claude).

## ChatGPT (Plugins)

Same remote MCP URL — ChatGPT calls these **Plugins** (Claude calls them **Connectors**).

1. **Settings → Security and login → Developer mode** on (plan / workspace dependent)
2. Open [chatgpt.com/plugins](https://chatgpt.com/plugins) → **+** → **New Plugin**
3. Name `geometry`, paste `https://mcp.geometry.app/mcp`, accept the risk checkbox → **Create**
4. **Sign in** / **Approve** if prompted — then `geometry` shows under Installed
5. Ask a date question in a new chat with the plugin enabled

Optional icon: PNG ≤10 KB from the [tutorial](https://geometry.app/tutorial/#chatgpt). Soft-launch URL needs no separate GEOMETRY account.

Authority: [OpenAI — Connect and test your plugin](https://developers.openai.com/plugins/deploy/connect-chatgpt).

Visual: [tutorial · ChatGPT](https://geometry.app/tutorial/#chatgpt).

## Codex

1. Run:

```bash
codex mcp add geometry --url https://mcp.geometry.app/mcp
```

2. Or add to `~/.codex/config.toml` (project: `.codex/config.toml`):

```toml
[mcp_servers.geometry]
url = "https://mcp.geometry.app/mcp"
```

3. Ask a date question in Codex

Visual: [tutorial · Codex](https://geometry.app/tutorial/#codex).

## Cursor

1. **Cursor Settings → Tools & MCP → New MCP Server** (opens `mcp.json`)
2. Add the remote server:

```json
{
  "mcpServers": {
    "geometry": {
      "url": "https://mcp.geometry.app/mcp"
    }
  }
}
```

3. **Toggle geometry ON** in Tools & MCP (easy to miss)
4. Ask a date question in Agent

Project file: `.cursor/mcp.json` · global: `~/.cursor/mcp.json`.

Visual: [tutorial · Cursor](https://geometry.app/tutorial/#cursor).

## VS Code

1. **Command Palette** → `MCP: Add Server` (or `MCP: Open Workspace Folder MCP Configuration`)
2. Add to `.vscode/mcp.json`:

```json
{
  "servers": {
    "geometry": {
      "type": "http",
      "url": "https://mcp.geometry.app/mcp"
    }
  }
}
```

3. **MCP: List Servers** — confirm geometry is Running
4. Ask a date question in Copilot Chat **Agent** mode

User profile: `MCP: Open User Configuration`. Key is `servers` (not Cursor’s `mcpServers`); HTTP needs `"type": "http"`.

Visual: [tutorial · VS Code](https://geometry.app/tutorial/#vscode).

## Then ask your AI

- "What's the birth card for March 15, 1985?" — *birth identity*
- "How compatible are two people born 1985-03-15 and 1990-11-08?" — *two people*
- "What's the card and planetary ruler for today, 2026-07-28?" — *one day*
- "What moon phase and season was 1985-03-15, and was anything retrograde?" — *deeper birth context*

Those map to the tools: [`get_birthdate`](/tools/get-birthdate) and [`get_compatibility`](/tools/get-compatibility) <Badge color="green" size="sm">Production</Badge>, plus [`get_day`](/tools/get-day) and [`get_name`](/tools/get-name) <Badge color="orange" size="sm">Beta</Badge>. Moon phase, season, and retrogrades ship inside the birth-card payload — no extra call.

**Full JSON in chat** (same as “raw JSON”):

> give raw json for birthdate 1985-03-15 card

That tells the **agent** to paste the complete tool result. The tool has no verbosity flag — only `birth_date`. If you read the MCP or HTTP response in code, you already get the full object every call.

No account to try. Fixed lookups — same date, same answer.
