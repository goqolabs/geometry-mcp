A name string in → per-word and full-name **Francis Bacon** cosmic cards, Latin cipher suite sums, and a periodic-element block from Chaldean.

| | |
|---|---|
| **Input** | `full_name` (text) — whitespace-separated words |
| **Engine** | Cipher **41** (`francis_bacon`) → `card_no` 1–52; other Latin ciphers as raw sums |
| **Version** | `v2.2.0` |
| **MCP URL** | `https://mcp.geometry.app/mcp` |

**Ask:**

> Decode the name KEEL with get_name

**Ask (raw JSON):**

> give raw json for get_name KEEL

## What you get

- Top-level `cipher_legend[]` (Latin suite metadata once)
- `words[]` — one entry per word plus a `"full"` aggregate
- Each word: Francis Bacon `card{}`, `arcs{}`, `archetype{}`, `periodic{}`, `ciphers[]`
